# Light in the field of view

Five interactive experiments show how gaze direction, seating position and room lighting affect the light measured at eye level. Compare readings in lux with the sensor open and with a radiance hood that limits its field of view.

Start the guided introduction in [English](https://jzauner.github.io/light_in_the_field_of_view/#en/intro) or [Deutsch](https://jzauner.github.io/light_in_the_field_of_view/#de/einstieg).

To use the demonstrator offline, open `index.html` in a browser from a local copy of this repository.
